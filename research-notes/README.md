## 公開に戻すときの判定基準

1. 実際の風景、そこで営まれている仕事、自然条件の関係を具体的に記述できるか。
2. 単なる施設紹介・事業紹介・一般論ではなく、読者に新しい発見を与えられるか。
3. 立地、歴史、規模、工程など、論旨を左右する根拠を確認できるか。
4. 既存の公開エッセイと論点が重複していないか。重複するなら統合を優先する。
5. 未確認の事柄を、推測だけで土地固有の事実として書いていないか。
