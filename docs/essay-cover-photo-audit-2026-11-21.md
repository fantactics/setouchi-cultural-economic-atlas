# SETOUCHI ATLAS — アイキャッチ写真再監査（2026-11-21）

目的：記事の問いと写真の一致を第一に、法的に利用できる写真を選ぶ。Wikimedia Commons 掲載自体は「パブリックドメイン」の証拠にはならない。

## 判断基準
1. **主題との一致**：記事が説明する物・作業・地形が写真から伝わること。
2. **地域の一致**：現地写真を優先。他地域の写真を使う場合は、代替・比較資料であることを alt とクレジットに明記する。
3. **利用許諾**：パブリックドメイン／CC0を優先。CC BY・CC BY-SAは表示要件を守る。単に公的機関が公開した画像を自由利用画像とみなさない。
4. **画質・見栄え**：カードでの切り抜き後も主要被写体が読めること。年代の古い資料写真は高解像度の現代の代替とは区別する。
5. **掲載の事実性**：写真が記事に書いた特定の工程・製品・場所を示すように誤認させない。
