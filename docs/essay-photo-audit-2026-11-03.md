# SETOUCHI ATLAS｜エッセイ写真監査
更新日：2026-11-03

## 対象と運用原則

対象は公開エッセイ全61篇（`src/pages/book/index.astro` で構成される `allBookArticles`）。カード写真・記事冒頭写真のどちらも、対象物と撮影地、出典・撮影者、ライセンス、写真を載せる理由を確認する。

- **第一優先：記事の主題そのもの。** 「ある土地についての文章」に別の土地の風景を無説明で当てない。
- **比較写真は比較と明記。** 岡山の寿司、沖縄のひじき採集、鴻島近隣の風景などを実地撮影と誤認させない。
- **権利未確認のメーカー・観光協会画像を無断で直リンクしない。** 許諾・ライセンスが確認できるまでリンク紹介にとどめる。
- **カード写真は `essayIndexPhotoOverrides` → `essayCardCopy.photoId` → 記事の `heroPhoto` / `heroPhotoId` → 本文写真の順に選ぶ。** 汎用の町・海の画像を無条件に代入しない。
- **新たに記事を追加するときは写真を選ぶか、理由のある「写真なし」を明示する。** 2026-11-03時点で写真なしを明示的に認めるのは `ai-era-regional-planning-learning-velocity` のみ。ほかの欠落はサイトビルド時に検出する。

## 検証と限界

サイトのビルドは、写真の設定欠落を静的に検出する。これは URL の到達性や画像の実表示、ライセンス条件の充足を保証するものではない。公開後の目視確認と、出典サイト側の URL・利用規約の再点検が必要。

現時点では画像を無理に生成せず、**現地写真 / 同じ地域の比較景観 / 地域外の比較写真 / 歴史絵画 / 写真なし**を区別して扱う。

## 2026-11-03：実物写真リンクと権利処理（追加調査）

- **岡山ばら寿司**：岡山県観光連盟の観光写真ライブラリーは観光PR目的等に利用目的を限定し、申込フォームを通したダウンロードを求め、画像への直リンクを禁止している。無断転載・直リンクを避け、公開紹介ページ（https://www.okayama-kanko.jp/gourmet/detail_11993.html）への読者向けリンクのみを記事に掲載した。利用条件：https://www.okayama-kanko.jp/business/photos/terms.html
- **三浦工業**：製品紹介ページ（https://www.miuraz.co.jp/product/boiler/）に実際のボイラ写真がある。許可やオープンライセンスを確認できていないため複製せず、記事からメーカー公式ページへリンクした。記事冒頭の松山市街は製品写真ではない。
- **瀬戸内の行商船**：香川県立瀬戸内海歴史民俗資料館が、所蔵するテグス行商船の高橋克夫撮影写真を公開（https://www.pref.kagawa.lg.jp/kmuseum/setorekishi/exhib/setonaikainokaijyouseikatu.html）。ライセンスを確認できていないため複製せず、記事から原資料へリンクした。冒頭は1911年頃の歴史絵画で行商船の記録写真ではない。
- **松山鮓**：Wikimedia Commonsの `Matsuyamasushi.JPG`（松山市中央卸売市場水産市場運営協議会、CC BY 3.0）を追加採用。瀬戸内の寿司エッセイ本文末尾の写真帳に使用し、松山鮓と明記する。岡山ばら寿司の写真の代用と称してはいけない。

サイト側の実装は `src/data/essayPhotoFieldReferences.js` に実物写真への原ページリンクを格納し、`src/pages/book/[slug].astro` から表示する。利用許諾が得られた場合のみ、該当の実物写真をサイト内へ掲載する。

## 継続作業：許諾申請を止めて、既存素材の適合性を改善（2026-11-03）

権利者への掲載許諾の取得は、現時点では制作作業の必須工程としない。利用条件が確認できた既存の写真を優先し、個別許諾が必要なものはリンク案内にとどめて制作を前進させる。

**鴻島シリーズ4篇の本文冒頭写真を補完。** 以前は一覧ページに写真があっても、各記事本文には `heroPhotoId:null` が指定されていた。実際の鴻島写真2点を `photoEvidence.js` に登録し、本文の冒頭にも表示するようにした。

- `photo-kojima-island-aerial`：国土地理院の鴻島航空写真。別荘ストック・空き別荘を扱う2篇に使用。国土地理院提供元への適切なクレジットを付す。
- `photo-kojima-island-from-sea`：松岡明芳氏の海上から見た鴻島（CC BY-SA 4.0）。水道・道路などのインフラと、サイクリングを論じる2篇で使用。設備やサイクリストの実写と誤認させない。

**留意点：** 写真の重複は、同じ島を扱うシリーズであり現地の別アングルを確保できていない場合には暫定的に許容する。無関係な他の島の写真へ置き換えるより、撮影対象が正しい写真を使う。
