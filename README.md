# 瀬戸内文化経済アトラス

地理・気候・歴史・港・食・産業・企業・暮らしを重ね、
「なぜこの町はこの町になったのか」を可視化する文化経済アトラスの試作版です。

## Prototype
- 赤穂
- 尾道
- 今治

## 技術構成
- Astro
- GitHub Pages
- GitHub Actions

## ローカル起動
```bash
npm install
npm run dev
```

## 方針
- 産業遺伝子を地域理解の主要軸とする
- Fact / Interpretation / Hypothesis を分離する
- 将来はAIエージェントが更新候補を作り、人間承認後に公開する
