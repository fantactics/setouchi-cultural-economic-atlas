# SETOUCHI ATLAS 瀬戸内アトラス

**ランドスケープ ＝ ネイチャー × カルチャー**

SETOUCHI ATLASは、瀬戸内を旅する人に向けた**風景から読むエッセイ集**です。

港町の路地、ため池、島のみかん畑、古い町並み、海辺の工場、食卓の一皿。その景色の背後には、地形や地質、雨、風、潮、水、生き物と、それに向き合い、工夫してきた人々の時間があります。

「なぜ、ここにこんな風景があるのだろう」。そんな小さな疑問から、生業、食文化、産業、港、交易、都市の歴史をたどります。目指すのは観光スポットの網羅でも研究論文でもなく、**読んだあと、同じ風景が違って見える発見**です。

## サイトの中心
- **エッセイ**：写真や目の前の景観を入口に、自然と人の営みの応答を描く読み物
- **地名から／自然条件から**：地域と、少雨・潮汐・地形などの切り口でエッセイを探す
- **写真・地図**：現地の風景と、背景となる地理の理解を支える
- **研究ノート・資料**：調査、検証、比較のための編集基盤。読者向けの主役ではない

エッセイのカテゴリは、食文化／農業景観／港と船／海と島／歴史的町並み／都市景観／工業景観／観光景観。

## 編集方針

**風景から、その土地の自然と人の営みを読み解く。**

現代の電気・石油・流通がつくった均質な表面をめくると、各地の地形、気候、水、潮、生態系が、その土地の成り立ちの基盤として見えてきます。**自然を軽視せず、しかし自然決定論にも人間決定論にもならない。** 自然条件と人々の意思・技術・文化がどう作用し合って景観を形づくったかを、時代の変化とともに描きます。

**多様性は最重要の編集原則の一つです。** 土地ごとの違いを大切にし、エッセイも一つの型に均しません。短い旅のスケッチから長い歴史物語、比較、食や産業の意外なつながりまで、作品ごとにふさわしい表現を選びます。目指すのは、読者が最初の風景を違う視点で見られる発見です。

文体は旅好きの一般読者に向けて平易かつ簡潔に。写真や地図は読み物の理解に必要なものを選び、装飾過多を避けます。著者自身の現地体験は、必要に応じ自然な一人称で記します。

**詳細な編集・執筆・写真・地図・検証ルールは [EDITORIAL_PRINCIPLES.md](./EDITORIAL_PRINCIPLES.md) を参照してください。**
