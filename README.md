# 瀬戸内自然文化経済アトラス

瀬戸内を「何があるか」だけでなく、「なぜこの町はこの町になったのか」「この地域で人は何を得られ、何ができたのか」「それがどう変わったのか」から読むリサーチ・アトラスです。

人口増加、人口維持、産業振興、経済成長を、地域経営の自明の目標とは置きません。人口、産業、交通、土地利用、環境の変化によって、人が得られるもの・できること・失うもの・難しくなることがどう変化したかを記述します。地域の未来を考えるのは、その分析の先です。

## 現在の構成

- **Research Chapters**  
  地形・水・生態系 → 生業 → 港・交易 → 地域能力 → 食・信仰・景観 → 都市 → 産業変容・AI・土地利用
- **Place Case Studies**  
  各地域を自然基盤、形成過程、産業・文化、現在の可能性と制約から読む
- **Comparative Reading**  
  産業進化モデル、都市形成モデル、地域能力、土地固有性の移動を横断比較
- **Atlas Concepts**  
  Capability、Industrial Commons、交通摩擦、滞留の経済、都市層序、結節点資本など
- **Maps & Evidence**  
  気候、地形断面、潮・風、海産物、交通、産業、繊維、写真証拠

## 編集原則

- FACT / INTERPRETATION / HYPOTHESIS / VALUE JUDGMENT を分離する
- 自然条件を決定因とせず、「可能性と制約」として扱う
- 「人口減少＝課題」「産業成長＝成功」といった価値判断を先に置かない
- 一つの変化について、利得と損失、可能になったことと難しくなったことを併記する
- 市町村境界だけでなく、流域＋沿岸海域、港＋後背地、産業ネットワークを分析単位にする
- 写真は装飾ではなく「何の因果・可能性・制約を示すか」で選ぶ
- 地域ページを政策提言で閉じず、変化・可能性・制約・選択肢・トレードオフを示して次の観測へ開く
