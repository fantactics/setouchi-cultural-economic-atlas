# 瀬戸内文化経済アトラス

瀬戸内を「何があるか」ではなく、「なぜこの町はこの町になったのか」から読む文化経済アトラスです。

## 現在の構成

- **Research Chapters 02–10**  
  地形・水・生態系 → 生業 → 港・交易 → 地域能力 → 食・信仰・景観 → 都市 → 石油文明と標準化
- **Place Case Studies**  
  20地域を18レイヤーで比較
- **Comparative Reading**  
  産業進化モデル、都市形成モデル、地域性の移動を横断比較
- **Atlas Concepts**  
  地域能力資本、交通摩擦、滞留の経済、都市層序、結節点資本、供給源の不可視化など
- **Maps & Evidence**  
  気候、地形断面、潮・風、海産物、交通、産業、繊維、写真証拠

## 編集原則

- FACT / INTERPRETATION / HYPOTHESIS を分離する
- 自然条件を産業の決定因とせず、「可能性と制約」として扱う
- 市町村境界だけでなく、流域＋沿岸海域、港＋後背地、島＋対岸を分析単位にする
- 写真は装飾ではなく「何の因果を示すか」で選ぶ
- 因果線は、検証済み／強い多因子関係／作業仮説を区別する
